# AI collaboration log

Record every user prompt in [docs/ai-logs.md](../../docs/ai-logs.md) as a numbered entry under the current date heading, with:

- **Prompt:** the user's words, quoted verbatim
- **AI suggestion/action:** what was proposed or done
- **Decision:** what the user accepted, changed, or declined

Update the log in the same turn as the work it describes. Stage it in that work's commit. Never make a commit that only changes `docs/ai-logs.md`. If a prompt produces no committable work, leave its entry uncommitted until the next work commit.
